Mini-annuaire ISTILE

Réalisé par : Tchouante Cyrille

Ce projet consiste à développer un mini-annuaire numérique des étudiants de l'ISTILE.
Il permet de présenter les étudiants et de consulter leurs informations à travers une interface web responsive.
Il utilise HTML5, CSS3 et JavaScript moderne pour exploiter des données JSON et communiquer avec une API.

Lancement du projet

Pour démarrer le programme, exécuter la commande suivante dans le terminal :

npm start
